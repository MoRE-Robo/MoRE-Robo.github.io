# MORE website assets

Put anonymized project media in this folder.

Suggested filenames:

- `method-overview.png` for the method diagram
- `teaser.mp4` or `teaser.gif` for the hero/demo result
- `demo-video.mp4` for a walkthrough video
- `result-a.png`, `result-b.png`, `result-c.png` for examples
- `paper.pdf` for the anonymous paper PDF

Before uploading, check that images, videos, PDFs, filenames, metadata, and
visible browser/desktop details do not reveal names, institutions, email
addresses, repository paths, or private hostnames.
